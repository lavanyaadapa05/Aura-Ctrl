AuraCtrl Voice Control Guide

Aura-Ctrl allows you to control applications, system settings, system information, and presentations using voice commands. The system uses speech recognition to convert spoken commands into real-time actions.

1. Starting Voice Control

  • Open Aura-Ctrl.
  • Click Start Voice.
  • The system will activate your microphone.
  • You will hear: "Voice Control System Started".
  • Wait for "Listening..." and speak clearly.

2. Opening Applications

  • "open chrome"
  • "open notepad"
  • "open calculator"
  • "open vscode"
  • "open file explorer"
  • "open settings"

3. Application Control

  • "minimise chrome"
  • "maximize chrome"
  • "close chrome"

4. Window Management

  • "arrange left right" → split screen
  • "arrange top bottom" → vertical split

14. Stopping Voice Control

  • Say "exit"
  • Or say "stop"
  • Or click Stop Voice button

15. Tips for Best Performance

  • Speak clearly and at a moderate speed
  • Reduce background noise
  • Use simple command phrases
  • Wait for "Listening..." before speaking
  • Ensure microphone permissions are enabled
