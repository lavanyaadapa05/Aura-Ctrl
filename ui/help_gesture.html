AuraCtrl Gesture Control Guide

Aura-Ctrl enables touchless computer interaction using real-time hand gesture recognition. Using your webcam and computer vision, the system detects hand landmarks and converts gestures into mouse and system control actions.

1. Getting Started

  1. Launch the Aura-Ctrl application.
  2. Click Start Gesture on the main screen.
  3. The webcam will activate automatically.
  4. Position your hand clearly in front of the camera.
  5. Ensure your hand is fully visible and well lit.

2. Cursor Movement

  • Raise your index finger.
  • Move your hand to control the cursor.
  • Smooth movements improve accuracy.

3. Left Click

  • Show index finger + pinky finger.
  • The system performs a left click.

4. Right Click

  • Show thumb + pinky finger.
  • This triggers a right click.

5. Scrolling

  • Raise index finger + middle finger.
  • Move hand up → scroll up.
  • Move hand down → scroll down.

6. Volume & Brightness Control

  • Make a fist (all fingers down).
  • Move hand up/down → control volume.
  • Move hand left/right → control brightness.

7. Zoom Control

  • Raise index + middle + ring fingers.
  • Increase distance → Zoom In.
  • Decrease distance → Zoom Out.

8. System Controls

  • One thumb → Open Chrome
  • Thumb + index + ring + pinky → Open Notepad
  • Ring + pinky → Open Calculator
  • All fingers up → Open Settings
  • Index + middle + ring + pinky → Alt+Tab (switch apps)
  • Only pinky → Close active window
  • Thumb + index + middle → Take screenshot

9. Stopping Gesture Control

  • Click Stop Gesture in the application
  • Or press X or ESC
  • Or close the camera window

10. Tips for Best Performance

  • Use a plain background.
  • Avoid multiple hands in the frame.
  • Ensure good lighting.
  • Keep your hand within camera view.
  • Move gestures slowly for better accuracy.
