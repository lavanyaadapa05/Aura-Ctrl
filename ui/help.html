AuraCtrl Help

Aura-Ctrl allows you to control your system using simple hand gestures and voice commands. Please follow the instructions below for smooth operation.

🤏 Gesture Control

Aura-Ctrl allows you to control your computer using hand gestures. Click Gesture Control to start gesture control.

How to Start Gesture Control

  1. Open the Aura-Ctrl application.
  2. Click on Gesture Control from the home screen.
  3. Allow camera access when prompted.
  4. Ensure your hand is clearly visible in front of the camera.
  5. Keep your hand within good lighting conditions.

🖱 Cursor Movement

  • Raise your index finger.
  • Move your hand to move the mouse pointer.
  • Move smoothly for better accuracy.

👆 Left Click

  • Bring your index finger and thumb close together.
  • Hold briefly and release.
  • This performs a single left click.

🖐 Drag & Drop

  • Bring index finger and thumb very close.
  • Hold them together to start dragging.
  • Move your hand to drag.
  • Separate fingers to drop.

👉 Right Click

  • Bring your thumb and pinky finger close together.
  • This triggers a right click.

🔄 Scroll

  • Join your index and middle fingers.
  • Move your hand up to scroll up.
  • Move your hand down to scroll down.
  • Keep movements slow and steady.

🔊 Volume Control Mode

  • Make a closed fist (all fingers folded).
  • Move hand up to increase volume.
  • Move hand down to decrease volume.

💡 Brightness Control Mode

  • Keep your hand in fist mode.
  • Move hand right to increase brightness.
  • Move hand left to decrease brightness.

🌐 Application Launch

  • Show only thumb up to open Chrome.
  • Show thumb, index, and pinky up to open Notepad.
  • Show all fingers up to open Settings.

📱 System Controls

  • Show thumb and pinky up to toggle Bluetooth.
  • Show thumb, index, and middle up to take a screenshot.
  • Show index, middle, ring, and pinky up to switch to next window/tab.

🔍 Zoom Control

  • Show index and middle fingers up.
  • Bring fingers closer together to zoom in.
  • Move fingers farther apart to zoom out.

⚠ Tips for Best Performance

  • Use a plain background.
  • Keep camera steady.
  • Avoid multiple hands in frame.
  • Good lighting improves accuracy.

🎤 Voice Control

Aura-Ctrl also supports voice commands for additional control. Click Voice based Control to start voice control.

How to Start Voice Control

  • Open the Aura-Ctrl application.
  • Click on Voice based Control from the home screen.
  • Ensure your microphone is working and not muted.
  • Speak clearly when prompted.

🖥 Application Control

  • Say "open [app name]" to open an application (e.g., "open chrome", "open notepad", "open calculator").
  • Say "close [app name]" to close an application (e.g., "close chrome").
  • Say "maximize [app name]" to maximize an application window.
  • Say "minimise [app name]" to minimize an application window.

🪟 Window Management

  • Say "arrange left right" to arrange two windows side by side.
  • Say "arrange top bottom" to arrange two windows stacked vertically.
  • Say "swap windows" to swap the positions of two active windows.

🔊 Volume Control

  • Say "volume up" to increase volume.
  • Say "volume down" to decrease volume.
  • Say "mute volume" to mute/unmute volume.

💡 Brightness Control

  • Say "brightness up" to increase screen brightness.
  • Say "brightness down" to decrease screen brightness.
  • Say "set brightness to [level]" to set brightness to a specific level (0-100).

🖱 Mouse Control

  • Say "mouse left" to move mouse left.
  • Say "mouse right" to move mouse right.
  • Say "mouse up" to move mouse up.
  • Say "mouse down" to move mouse down.
  • Say "click" to perform a left click.
  • Say "double click" to perform a double click.

📜 Scrolling

  • Say "scroll up" to scroll up.
  • Say "scroll down" to scroll down.

📸 Screenshot

  • Say "take screenshot" to capture and save a screenshot.

📶 WiFi Control

  • Say "wifi on" to turn WiFi on.
  • Say "wi-fi off" to turn WiFi off.

🛑 Stopping Voice Control

  • Say "exit" or "stop" to stop voice control.

📊 PowerPoint Control

Aura-Ctrl supports voice commands for controlling PowerPoint presentations.

📂 Presentation Management

  • Say "open powerpoint" to connect to PowerPoint.
  • Say "create new presentation" to create a new presentation.
  • Say "create slide about [topic]" to add a new slide with the specified topic.

🎬 Presentation Control

  • Say "start presentation" to begin the slideshow.
  • Say "next slide" to go to the next slide.
  • Say "previous slide" to go to the previous slide.
  • Say "stop presentation" to end the slideshow.

💻 VS Code Coding

Aura-Ctrl supports voice-controlled coding in VS Code. Open VS Code and use these commands to create, edit, and run Python programs.

🖥 Opening VS Code

  • Say "open vs code" to launch Visual Studio Code.

📄 File Management

  • Say "open new file" to create a new file.
  • Say "title as [filename]" to name the file (e.g., "title as one.py").
  • Say "save" to save the current file.
  • Say "close" to close the current file.

🤖 AI Code Generation

  • Say "write a program to [description]" to generate Python code using AI (e.g., "write a program to see whether a number is odd or even").

▶ Running Code

  • Say "run with test case [input]" to execute the program with a test input (e.g., "run with test case 2").
  • The code runs in VS Code's integrated terminal.

⚠ Notes

  • Ensure VS Code is the active window when using file commands.
  • Currently supports Python programming.
  • AI code generation requires an internet connection.
